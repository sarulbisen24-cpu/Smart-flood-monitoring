# Smart Flood Monitoring & Alert System

## Track
Disaster Management & Urban Resilience

## Problem
Heavy rainfall can cause rapidly rising water levels and flooding.
Early detection of rising water can help provide timely warnings.

## Our Solution
We are developing an IoT-based system that monitors water
level using an ultrasonic sensor connected to an ESP32.

## Main Features
- Real-time water-level monitoring
- Safe / Warning / Danger status
- Flood alert
- Web dashboard
- Emergency information

## Hardware
- ESP32
- Ultrasonic sensor
- Breadboard
- Jumper wires
- USB cable

## Technology
- ESP32
- Arduino IDE
- HTML
- CSS
